MLBB COACH · V2.1

Pair your screenshot Shortcut

This is a one-time setup. Once paired, the Shortcut never needs a match token again.

Pairing action (first run only)

  1. In the Coach dashboard, tap Generate pairing code.
  2. In Shortcuts, create a temporary pairing action: Ask for Input (Text), paste the pairing code.
  3. Get Contents of URL → https://mlbb.mtgrumble.com/api/devices/claim → POST → Request Body JSON → key code = the provided input.
  4. Extract the captureKey field from the response using Get Dictionary Value.
  5. Save File with that value in the Shortcuts iCloud Drive folder as mlbb-capture-key.txt. Keep this file private.

Every screenshot

  1. Get File from Folder → mlbb-capture-key.txt; read its text contents.
  2. Take Screenshot.
  3. Get Contents of URL → https://mlbb.mtgrumble.com/api/devices/capture → POST → Request Body File = Screenshot.
  4. Set headers: Content-Type: image/png and Authorization: Bearer [saved capture key].
  5. Optionally Show Result for testing; remove this action once working.

Set the Shortcut under iOS Settings → Accessibility → Touch → Back Tap → Double Tap.

Shortcuts action labels vary by language/iOS release. The app cannot silently install or configure a Shortcut. A published iCloud Shortcut sharing URL can be configured as SHORTCUT_INSTALL_URL on the server to simplify installation.
